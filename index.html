Desarrollo web I

Descripción del curso

Desarrollo web I es el curso fundamental que introduce los lenguajes esenciales para crear aplicaciones web: HTML, CSS y JavaScript. Aprendemos a diseñar sitios web atractivos y funcionales, crear aplicaciones interactivas de front-end y comprender la arquitectura de aplicaciones web modernas.

Contenidos principales

  • Unidad I-II: Introducción al HTML y CSS
  • Unidad III-IV: Maquetación de sitios web y frameworks responsivos
  • Unidad V: Introducción a JavaScript
  • Unidad VI: DOM y JavaScript asíncrono
